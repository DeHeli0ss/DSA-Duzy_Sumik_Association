# DSA-Duzy_Sumik_Association
Repozytorium zawiera struktury tabel, skrypty SQL oraz dokumentację projektu bazy danych stworzonej na potrzeby stowarzyszenia wędkarskiego Duży Sumik Association (DSA). 

Celem projektu jest utrzymanie spójnej i uporządkowanej bazy danych członków stowarzyszenia, ich uprawnień, opłat oraz działalności organizacyjnej.

Repozytorium jest przeznaczone wyłącznie do użytku wewnętrznego przez trzech członków zespołu projektowego.
